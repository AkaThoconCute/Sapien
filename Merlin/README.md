# Merlin

## 1. Introduction

Merlin is the content improvement and inspection project of Sapien, with AI agent features:

- **Inspect**: automatic content checks (SEO, images, ...).
- **ARR**: when a source document changes, related articles are automatically recommended to their authors for update.
- **PCP**: chat with AI to draft a complete article or edit content without clicking buttons; customize the AI with your own rules; edit articles in VS Code and create articles through MCP.
